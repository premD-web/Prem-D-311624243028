# Phase 02 — Ideation — Define the Problem

**Project:** Script-Controlled ACL – Restrict Record Access Based on Field Value  
**Team ID:** SWTID-2026-4677  
**Team:** Botbyte

## Purpose
Problem statements, target users, current difficulty, root cause, impact and selected problem focus.

## Project content
### Problem statement A
- User: Service desk / Incident user
- Trying to: Access records needed for work
- But: Broad rules may expose too many records
- Because: Access may not reflect record-level conditions
- Impact: Restricted information may be exposed

### Problem statement B
- User: ServiceNow administrator
- Trying to: Apply field-based access rules
- But: Role-only rules cannot express every record condition
- Because: Access needs can depend on field values
- Impact: Manual work and security risk increase

### Selected focus
Restrict Incident record access by evaluating an approved field value in a server-side scripted ACL.
